The 5-Gate Workflow

DEVELOPMENT CYCLE // INTENT TO PRODUCTION

Gate 1: UNDERSTAND // Intent & Scope

Agent explores user requirements, performs research, and persists requirements.md. Awaits human confirmation.

Gate 2: ANALYZE // PRD & Feasibility

PM and PO agents write user stories, define acceptance criteria, and evaluate risks, persisting analysis.md.

Gate 3: PLAN // System Architecture

Architect designs APIs, defines ADR schemas, creates task_plan.md and design.md. Awaits architecture approval.

Gate 4 & 5: IMPLEMENT & VERIFY

Engineering agents implement tasks via TDD, DevOps sets up pipelines, QA verifies test pyramid and code review.
